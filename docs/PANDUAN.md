# Menggunakan dan merawat Belajar Islam

## Sesi belajar pertama

1. Dari Beranda, pilih Lanjutkan pelajaran. Baca penjelasan, lihat istilah dan buka sumber bila terhubung ke internet.
2. Tandai sudah membaca dan jawab semua soal. Penjelasan muncul segera setelah memilih jawaban. Soal yang salah mendapat prioritas dalam sesi berikutnya untuk pelajaran itu.
3. Buka Kamus istilah dan tandai kata yang ingin dipelajari sebagai favorit. Pada Latihan ingatan, ucapkan artinya sebelum memilih Lihat arti. Pilih Saya ingat atau Ulangi di akhir sesi. Sesi kartu dimulai kembali jika halaman ditinggalkan.
4. Gunakan Bacaan dan audio untuk mendengar Basmalah. Tandai Sudah hafal untuk menjadwalkan pengulangan pada hari berikutnya. Periksa pelafalan dengan guru.
5. Tulis pertanyaan di Catatan dan pertanyaan. Setelah bertemu guru, simpan jawabannya dan tandai sudah dijawab.

Grafik aktivitas memakai tujuh tanggal lokal terakhir. Untuk empat pelajaran tersedia dari 18 topik, menyelesaikan semuanya menghasilkan 22% dari rencana lengkap. Pilih tahap lain atau lompati urutan jika ingin melihat materi tertentu. Di Pengaturan, pencatat shalat dapat dinyalakan untuk menampilkan lima kotak centang harian di Beranda.

## Penyimpanan dan pemeliharaan

Aplikasi statis dimuat dari dist. Vue merender komponen dan halaman. Pinia mengelola navigasi serta state. Aksi baca, kuis, hafalan, catatan dan pengaturan masuk ke lapisan Dexie sebagai snapshot IndexedDB. Cache service worker menyimpan aplikasi dan media untuk offline. Berkas JSON ekspor memuat data pribadi termasuk catatan; simpan di tempat pribadi.

Untuk memindahkan perangkat, ekspor lewat Pengaturan, pilih JSON di perangkat tujuan, periksa ringkasan, lalu konfirmasi penggantian. Ekspor data tujuan lebih dahulu bila diperlukan. Jika browser menolak penyimpanan, periksa izin dan ruang tersedia sebelum melanjutkan. Gunakan satu tab saat mengedit untuk menghindari perubahan bersamaan.

## Materi dan tinjauan

Tersedia empat pelajaran lengkap dengan total 12 soal. Dua modul baru mengulas enam perkara iman menurut Sahih Muslim 8a dan lima dasar Islam menurut Sahih al-Bukhari 8. Tautan rujukan dan perawi ada di setiap pelajaran. Empat belas topik masih berupa rencana. Rekaman lokal tersedia untuk Basmalah. Seluruh materi contoh menunggu tinjauan guru. Lihat ../content/README.md untuk struktur JSON, nama berkas, metadata sumber dan prosedur tinjauan.
